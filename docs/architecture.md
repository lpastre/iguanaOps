## Frontend 
Será desenvolvido a última versão do Angular estavel.
Layout deverá ser responsivo com uma aparencia moderna e de fácil navegação, super intuitiva, limpa e bonita com cores claras, mas com opção de dark.

## Backend
As technlogias para serviços Restful serão:
linguagem: Java 25 
Framework: Spring-boot úlitma versão estável disponivel.
Libs principais: Actuator para health-check, Swagger(open-api) para documentacao
tipo de compilacao: Compilacao-nativa
Maven
banco de dados: SQLite
